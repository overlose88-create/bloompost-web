자주 발생하는 문제 — macOS

❶ "BloomPost.app이(가) 손상되어 열 수 없습니다" 오류

macOS가 다운로드된 앱을 차단하는 보호 기능이에요. 터미널(앱 → 유틸리티 → 터미널)을 열고 아래 명령을 붙여넣으세요:

xattr -cr /Applications/BloomPost.app

실행 후 앱을 다시 열면 정상 동작합니다.

❷ 우클릭해도 "열기" 메뉴가 없어요

Finder에서 앱을 한 번 더 클릭해 선택한 뒤, Control 키를 누른 상태에서 클릭하거나 트랙패드 두 손가락 클릭을 시도해 주세요.

❸ Apple Silicon (M1~M4) 사용 중인데 실행이 안 돼요

드물게 Rosetta 2 설치가 필요할 수 있어요. 터미널에서:

/usr/sbin/softwareupdate --install-rosetta --agree-to-license

자주 발생하는 문제 — Windows

❶ Windows Defender / 백신이 차단해요

코드 서명되지 않은 앱이라 가끔 백신이 오탐(false positive)을 합니다. "이 파일 허용" 또는 "앱 신뢰"로 예외 추가해 주세요. (V3, 알약, Norton 등 모두 동일)

❷ "이 앱은 PC에서 실행할 수 없습니다" 오류

Windows 32-bit 버전을 쓰고 있을 가능성이 있어요. BloomPost는 64-bit 전용입니다. 설정 → 시스템 → 정보에서 "시스템 종류"를 확인해 주세요.

❸ "VCRUNTIME140.dll을 찾을 수 없습니다" 오류

Microsoft Visual C++ 재배포 패키지가 필요해요. 아래 링크에서 받아 설치 후 다시 실행하세요:

📥 vc_redist.x64.exe 다운로드
